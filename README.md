# Первая форма на C# в Uno Platform

Учебный проект на .NET 10, C# и XAML. Приложение работает в браузере через WebAssembly.

1. На странице репозитория нажмите **Use this template → Create a new repository**.
2. В своей копии нажмите **Code → Codespaces → Create codespace** и дождитесь подготовки среды.
3. В терминале из корня репозитория выполните:

   `dotnet run --project SPOUno/SPOUno.csproj -f net10.0-browserwasm -- --urls http://0.0.0.0:5000`

4. Откройте порт **5000** во вкладке **Порты**. Чтобы остановить приложение, нажмите Ctrl+C в терминале.

Введите «Анна» и нажмите «Поприветствовать». Форма должна вывести «Привет, Анна!». Если поле пустое, появится подсказка «Введите имя.».

Разметка находится в `SPOUno/MainPage.xaml`, обработчик нажатия — в `SPOUno/MainPage.xaml.cs`.
